Site Plan Key Decryptor

Cuma jalan lokal di browser (tidak kirim data ke mana-mana). Sama persis dengan ProxyCipher.decryptString di lib/core/network/proxy_cipher.dart: AES-256-CBC, key sama dengan yang di-hardcode di sana, format input <ivBase64>:<ciphertextBase64> (boleh ditempel utuh dengan prefix URL .../siteplan-key?= di depannya, akan otomatis dipotong).
